# TheRoom WLED + Room Combined Firmware Control Parity Matrix

- **Project Delivery**: V14 (Android `0.4.0` / `versionCode 11`)
- **Target Combined Firmware**: `2.0.1-wled-room` (Upstream WLED `0.16.0` / `16.0.1` + `AudioReactive` usermod + `RoomBridgeUsermod`)
- **Target Hardware**: Classic dual-core ESP32 (4 MB flash), LED GPIO 23 (300 px default), INMP441 I2S Mic (BCLK 26, WS 25, SD 35), IR TX 18 / RX 27, SSD1306 OLED (SDA 21, SCL 22), Rotary Encoder (32, 33, SW 4), 4 Tactile Buttons (13, 14, 16, 17).
- **Zero WebView / Portal Policy**: Every supported control in the combined firmware has an app-owned Jetpack Compose equivalent in `in.roomcontroller.app`. `WledBrowser.kt`, `WledTheme.kt`, and `androidx.webkit` have been removed.

## 4. Intentionally Excluded or Compile-Time Disabled Features

| Excluded Feature | Firmware Evidence (`platformio_override.ini` / `Config.h`) | Reason & App Behavior |
| --- | --- | --- |
| 2D Matrix Layout & 2D Effects | `-D WLED_DISABLE_2D` (`info.leds.matrix` absent) | Disabled in combined firmware to conserve flash and IRAM for Room HTTPS + Spotify TLS. App hides 2D matrix editors when `info.leds.matrix == null`. |
| Amazon Alexa Voice Emulation | `-D WLED_DISABLE_ALEXA` | Disabled in combined firmware; excluded from Sync settings. |
| Adalight / TPM2 Serial | `-D WLED_DISABLE_ADALIGHT` | USB UART (`115200` baud) is owned by Room's line-delimited JSON maintenance console (`Serial.cpp`). |
| Improv Serial Provisioning | `-D WLED_DISABLE_IMPROV` | Disabled in combined firmware for the same UART ownership reason; Wi-Fi provisioning is performed natively in-app. |
| Unverified Stock WLED `/update` Binary Upload | `ESP32-WLED-MIGRATION.md` §7 | Flashing a generic stock WLED binary overwrites `RoomBridgeUsermod`, IR, Spotify, OLED, and pinned HTTPS services. Firmware updates are gated through Room's signed `/v1/ota` manifest workflow. |
| Legacy Room 5-Second Noise Floor Calibration on WLED-Owned Mic | `ESP32_APP_SYNC_CONTEXT.md` §14.2 | When WLED `AudioReactive` owns I2S (`BCLK 26, WS 25, SD 35`), noise gating is controlled via AudioReactive `squelch` (`0..255`) and `agc` (`0..3`). Legacy Room `calibrate` is enabled only when connected to legacy Room-owned microphone firmware. |
